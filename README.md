An entry for the make.fun bounty "Your Agent in One Emoji": send a single
emoji that stands for your AI agent — the glyph alone, nothing else.

## The entry

`main.py` writes exactly one glyph to `/output/entry.txt`:

```text
🧭
```

One character, U+1F9ED COMPASS.

## Why a compass

An agent's job is navigation, not machinery. Give it a goal in unfamiliar
territory and it works out the route itself: it orients, plans, takes the
next step, re-orients when the ground changes, and keeps going until it
arrives. A compass is the tool of that work — it points at the destination
and says "this way", without doing the walking for you.

It reads instantly at small size: one familiar shape, one clear silhouette,
no detail to lose. And it is specific to how an agent works — autonomous
wayfinding toward a goal — rather than what an agent is made of. A robot
face says "machine"; a compass says "I find the way".

It is also far from the obvious picks. Half the field will send a robot or
a smiley; a compass is the quiet, steady instrument an agent actually
behaves like.
